# Procedure
1. Search the company's own materials for the detail behind the claim (search_company_docs).
2. Ask which public source could establish it. In this MVP no reimbursement (CMS) or funding
   (NIH RePORTER) tool is integrated, so most commercial claims remain company_reported_only.
3. Reimbursement: FDA clearance does not imply Medicare coverage; coverage and coding are separate
   processes. Record the specific check a specialist should run.
4. Customers, revenue, pricing, adoption: public sources rarely establish them. Ask for contracts,
   invoices or reference calls rather than guessing.
5. Prefer an explicit open question over a substantive verdict without independent evidence.
