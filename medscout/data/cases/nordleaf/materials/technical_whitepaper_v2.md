# PulseWeave Technical Overview (v2)
Date: 2025-11-02
Document: technical whitepaper. FICTIONAL company for the MedScout demo.

## Device description
PulseWeave records a single-lead ECG continuously and runs an on-device arrhythmia detection algorithm. Data are uploaded to a secure cloud portal for physician review.

## Regulatory status
PulseWeave received FDA 510(k) clearance (K251234) in February 2025.

## Algorithm performance
In a retrospective validation on 2,400 annotated recordings, the algorithm achieved 96.1% sensitivity and 94.0% specificity for atrial fibrillation.

## Ongoing research
The PULSE-AF trial is enrolling up to 600 participants at 12 sites.
